## 🚀 Featured Projects

### 🧪 Mutation Lab — *jeu Roblox multijoueur, avec un partenaire* (Automne 2026)

Jeu Roblox de collection et de mutation de créatures, programmé en **Luau**.

- Économie de jeu complète : double monnaie, marché entre joueurs et tableau des meilleurs joueurs.
- Système de sauvegarde basé sur **DataStore** avec reprise automatique, protection contre la corruption des données et résolution de conflits, pour éviter toute perte de progression entre serveurs.
- Hub central généré procéduralement par script (structure et entrées alignées en code).
- Optimisation des performances (élagage par distance, animations automatisées) pour supporter plusieurs joueurs simultanément.

### 🃏 Super Cartes Infinies — *projet d'équipe* (Hiver 2024)

Jeu de cartes en ligne séparé en un dépôt serveur et un dépôt client.

- Serveur **ASP.NET Core Web API + MVC** avec combats multijoueurs en temps réel via **SignalR**.
- Authentification avec **ASP.NET Core Identity** et **JWT**.
- Domaine du jeu modélisé avec **Entity Framework Core** et **SQL Server**.
- Client **Angular** : connexion et inscription, boutique de cartes, écran de combat.
- Logique de combat couverte par des **tests unitaires**.

### 🎮 ValEsportDBFIRST — *projet solo* (Hiver 2025)

Application web dédiée à la gestion d'équipes eSport sur Valorant.

- Développée avec **ASP.NET Core MVC** et **Entity Framework Core** en approche **DB First**.
- Gestion d'équipes et de joueurs connectée à **SQL Server**.
- Architecture MVC, accès aux données et validation.

### 📱 Application mobile Android — *projet de cours*

Application mobile développée en **Kotlin** pour **Android**.

### ⚛️ FirstReactProject

Application React moderne créée pour pratiquer le développement front-end.
